# 管理画面デザインシステム — 「和紙と墨」(EC-8 UI刷新)

茶会サービスの管理画面にふさわしい、落ち着いた和モダンのデザイン言語。
Tailwind デフォルトの寄せ集めにせず、専用トークン + 共通コンポーネントクラス
（`globals.css` の `wa-*`）で全画面を統一する。

## コンセプト

- **紙**: 生成りの和紙 (washi) を地に、カードは白茶 (shiro) を一段浮かせる
- **墨**: 文字・主ボタンは墨色 (sumi)。真っ黒は使わない
- **抹茶**: 肯定・確定・予約あり・成功 = 抹茶 (matcha)
- **朱**: 注意・未確認・定休・今日 = 朱 (shu)。面で塗らず、細い罫・点・淡い地で効かせる
- **金茶**: 公開中の枠・補助アクセント = 金茶 (kin)

## カラートークン（globals.css `@theme`）

| token | 値 | 用途 |
|---|---|---|
| `washi` | `#f4efe5` | アプリ背景（生成り） |
| `washi-deep` | `#eae3d3` | インセット背景・ホバー地 |
| `shiro` | `#fbf9f3` | カード・サイドバー・ドロワーの面 |
| `sumi` | `#262320` | 見出し・本文・主ボタン地 |
| `sumi-mid` | `#5c564d` | 副文 |
| `sumi-soft` | `#958c7d` | ラベル・補足 |
| `line` | `rgb(38 35 32 / 12%)` | 罫線（hairline） |
| `matcha` / `matcha-deep` / `matcha-mist` | `#66794f / #4a5a3a / #edefdf` | 確定・予約あり |
| `shu` / `shu-deep` / `shu-mist` | `#b8492c / #96371f / #f7e7df` | 未確認・警告・今日 |

## タイポグラフィ

- 見出し・数字・日付: **Noto Serif JP**（`.wa-serif`、next/font で admin レイアウトに読込）
- 本文・UI: **Noto Sans JP**（admin ラッパーに適用）
- KPI 等の数字は `.wa-num`（tabular-nums）で桁を揃える
- セクションラベルは `.wa-label`（11px・letter-spacing 0.14em・sumi-soft）

## 面・影・角丸

- カード: `.wa-card` = shiro 地 + line 罫 + 二層の繊細な影（`0 1px 2px / 0 6px 20px`、透過6%以下）
- ドロワー・ボトムシート: `.wa-shadow-lg`（浮遊感のある大きめの影、それでも淡く）
- 角丸: カード 12px (`rounded-xl`) / ボタン 8px (`rounded-lg`) / バッジ full
- 強い drop-shadow・グラデーションは使わない

## コンポーネント規約

- 主ボタン `.wa-btn-primary` = 墨ベタ + 生成り文字（保存・ログイン）
- 肯定ボタン `.wa-btn-matcha` = 抹茶ベタ + 白文字（確定・公開）
- 破壊/否定 `.wa-btn-danger` = 朱の罫 + 朱文字のゴースト（キャンセル・非公開）
- 汎用 `.wa-btn-ghost` = line 罫 + sumi-mid 文字
- バッジ `.wa-chip` = 淡い地 (mist) + 濃い文字、枠線なし
- ステータス色: 未確認=朱 / 確定=抹茶 / キャンセル=灰 / 支払済=抹茶 / 未払=金茶
- カレンダー凡例: 公開中=金茶ドット / 予約あり=抹茶ドット / 非公開=灰ドット / 今日=朱リング
- ナビ: PC サイドバー = shiro、アクティブ項目は墨ベタ。モバイル下タブ = shiro + blur、
  アクティブは朱 + 上部インジケータ

## 制約

- 管理画面 (`/admin`) のみ。公開側 (`[locale]`) のトークン・スタイルには触らない
- API・データ構造・認証・ロジックは不変（見た目のみ）
